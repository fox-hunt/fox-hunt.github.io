# Охота на лис

Логическая игра по мотивам игры А. Несчётного («Наука и жизнь», № 12, 1985).
На поле спрятаны лисы. Открытая клетка показывает, сколько лис на её горизонтали, вертикали и диагоналях. Найдите всех за наименьшее число ходов.

Разработчик: Ирина Мальцева · maltsevaie@gmail.com

- `index.html` — игра (исходник)
- `assets/` — иконки
- `build.sh` — собирает сайт в `docs/` (его показывает GitHub Pages)
- `tests/` — тесты: `sh tests/run.sh` (функция бота на подставных Telegram и базе + игра в Chrome; нужны Node.js и Google Chrome)
- `Перспективы развития.md` — планы: монетизация (звёзды, украшения, реклама)
